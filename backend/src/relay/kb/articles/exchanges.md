title: Exchanging an item
category: returns

## We don't do direct exchanges
To get a different size, color or model, return the original item for a refund and place a new order for the one you want. This is the fastest way to get the new item, because it ships right away instead of waiting for your return to arrive.

## Price differences
The new order is charged at the current price, and the return is refunded at the price you paid.
