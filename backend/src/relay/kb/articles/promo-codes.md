title: Promo codes and discounts
category: orders
---
## Using a promo code
Enter the code at checkout. One promo code can be used per order, and codes can't be combined with other offers unless the offer says so.

## Codes after ordering
A promo code can't be applied to an order that has already been placed.

## Returns on discounted orders
If you return an item from a discounted order, the refund is the price you actually paid for that item.
