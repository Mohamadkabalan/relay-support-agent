---
title: How to start a return
category: returns
---
## Ask our support assistant
Tell the assistant which order and which items you want to return and why. It checks that the items are eligible and still inside the return window, shows you a summary with the estimated refund, and asks you to confirm.

## Your return authorization
After you confirm, you get a return authorization number (RMA) that starts with "RMA-", plus a link to a prepaid shipping label.

## Returning part of an order
You can return some items from an order and keep the rest, and you can return part of a quantity, for example one of two cables.
